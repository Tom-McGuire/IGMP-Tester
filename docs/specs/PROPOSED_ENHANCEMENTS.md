# IGMP & Multicast Tester — Proposed Enhancements & Suite Integrations

---

## Issue 1: Passive Multicast Stream Listener Mode (Rx)

### Summary
Add a **"Passive Listener"** mode to the Receiver (`Rx`) tab capable of subscribing to live multicast groups (such as sACN `239.255.0.x:5568` or Art-Net `239.255.x.x:6454`) and measuring packet rate (pps) and throughput (Mbps) without requiring the proprietary 50-byte `"IGMPTEST"` framing header.

### Motivation
Currently, `IGMP-Tester` Rx expects streams generated by the `IGMP-Tester` Tx engine to compute sequence gaps. In live venue or lab troubleshooting, engineers frequently need to join existing sACN, Dante, or MPEG-TS multicast streams from hardware transmitters to verify IGMP snooping delivery and per-group bitrates.

### Proposed Implementation
- Add a toggle in the Rx configuration toolbar: **Test Stream Mode (`IGMPTEST` Sequence Tracking)** vs. **Passive Traffic Mode (Raw UDP Rate/Throughput)**.
- In Passive Traffic Mode, join the configured multicast groups via `RawDatagramSocket.joinMulticast`, track packets/sec, bytes/sec, and source IP per group, and bypass `"IGMPTEST"` header validation.
- Include a quick-join preset for **sACN Universes 1–20 (`239.255.0.1` – `239.255.0.20`, UDP `5568`)**.

### Acceptance Criteria
- [ ] Rx tab accurately joins standard multicast groups and reports live PPS, Mbps, and sender source IP for non-`IGMPTEST` UDP traffic.
- [ ] Leaving/stopping cleanly dispatches OS IGMP Leave reports.

## Issue 2: Real-Time RFC 5424 Syslog Alerting on Querier Loss & Stream Gaps

### Summary
Add an optional **Syslog Forwarder** setting that emits standard RFC 5424 UDP Syslog alerts to a configurable host/port (default `127.0.0.1:514` or `5140`) when critical multicast anomalies occur.

### Motivation
Sending events directly to **Syslog Server** creates a unified chronological timeline correlating multicast drops or querier timeouts with switch port state changes and firewall logs.

### Trigger Events
- **Querier Watchdog Warning (`>125s`) / Critical (`>260s`):** Severity `Warning` / `Critical`
- **Active Querier IP Change:** Severity `Notice`
- **Packet Loss Gap Detected:** Severity `Error` (including group address, missing sequence range, and silence duration)

### Acceptance Criteria
- [ ] Optional toggle in settings to enable Syslog forwarding with target IP and UDP port.
- [ ] Emitted packets parse cleanly as RFC 5424 entries in `Syslog-Server`.
